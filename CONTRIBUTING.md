# Contributing

This repository is public so that its work can be read and checked, but it
is not open source (see [LICENSE](LICENSE)). For that reason pull requests
from outside the project are not merged.

Issues are welcome:

- **A chart that looks wrong.** Use the "Wrong chart" form. It asks for the
  calculation receipt the birth chart page offers for download, because it
  states the inputs, conventions and engine version that produced the chart.
- **A statement on the site that is wrong or unsupported**, with what you
  believe is correct and your source.
- **A broken page, link or control**, or an accessibility problem, with the
  address, the browser and what happened.

The chart engine and its conformance suite are open source and take
contributions in their own repository,
[zodiacs-org/engine](https://github.com/zodiacs-org/engine).

Security problems go through [SECURITY.md](SECURITY.md), not public issues.
Everyone taking part follows the [code of conduct](CODE_OF_CONDUCT.md).
