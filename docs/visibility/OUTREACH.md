# Outreach targets: "best astrology app / site" pages and directories

Collected 2026-11-08 through the session's web search tool (US). The pages
themselves could not be opened from this session, so titles, dates and the
competitors named come from search titles and snippets, and **whether
zodiacs.org is already listed is unchecked for every row**. Full records:
`baseline/2026-11-08/rankings.json` (`outreach`).

What the assistants actually cite is still to be measured: once
`ai-answers.mjs` has run, the `citedHosts` on questions q42 to q44 ("best free
astrology website", "best astrology app", "private birth chart no signup")
give the real list, and this file is re-ranked by how often each page is cited.

Nothing here has been contacted. Dias sends every message. The ask is the same
everywhere: a fair look at a free, no-account birth chart and astrology tool
site for the next update of the list. No payment, no link swap, no
sponsored placement. Pages that sell placements (marked below) are listed only
so we know they exist.

## Before sending anything

1. Open each page and record: still live, last updated, who is listed,
   whether zodiacs.org is there, the author's contact route.
2. Draft one short, specific note per page for Dias (what the page lists, what
   zodiacs.org adds that the list lacks: full chart with houses, no account,
   calculated in the browser, dated computed data). No crypto, token or market
   words, no em or en dashes.
3. Dias sends. Log replies and new listings in this file with dates, so the
   week 4 and week 8 AI re-runs can be read against them.
