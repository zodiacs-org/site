## Routine reminders

- Draft pull requests only. Never push to `main`.
- Commit as "Zodiacs Admin <admin@zodiacs.org>".
- No em or en dashes in copy.
- A change under `src/components`, `src/lib`, `src/islands`, `src/styles`, `src/layouts`, `src/pages/horoscopes` or `src/pages/today` moves the Phase 1 template digest. To fix it:
  1. Add `<!-- browser-evidence -->` and `<!-- browser-evidence-candidates head=<full sha> -->` to the pull request body.
  2. Download the candidates artifact.
  3. Copy its `docs/acceptance/phase1/` into the repo.
  4. Run `npx vitest run scripts/phase1-acceptance-evidence.test.mjs`, then commit.
- A changed page needs a newer sitemap date (`src/pages/sitemap.xml.ts`). The "Changed pages carry new sitemap dates" check lists any page that was missed.
- Protected paths (`scripts/phase1-scope-guard.mjs`) need a one-time allowance in `.github/phase1-scope-allowance.json`, pinned to the current `main`.
