## How it was scored

The first tool called must be one the question accepts. For `none`, no tool may be called.

Three questions give another person's birth details without saying that person agreed. The instructions say "Ask
before using someone else's birth details.", so the expected answer is `none`: the assistant asks, and calls nothing
yet. All but one of the misses are these. `RESULTS.md` also gives the count if calling the tool straight away were
accepted there, which is how the builder's 200 scored such questions.
