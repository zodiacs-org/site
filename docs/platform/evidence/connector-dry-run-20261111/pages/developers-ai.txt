# Build with the sky
Zodiacs connects AI assistants to the Zodiacs engine in two ways: a hosted MCP server at https://zodiacs.org/mcp for any assistant that accepts remote MCP connections, and a local developer plugin that runs on your own machine. Public directory listings remain release gates.
Looking for the app? See the cards, short demo and current connection options for ChatGPT and Claude </apps/>.
## Connect it
To use it in Claude, open Customize, then Connectors, add a custom connector and enter https://zodiacs.org/mcp. Other assistants that accept remote MCP connections use the same address. Then ask one of the questions below.
## The hosted server
The hosted server computes positions at an explicit instant, finds sign ingresses, stations and new/full Moons in a window of up to 92 days, and checks astronomical claims. Answers include UTC, a display timezone, calculation receipts and numerical limits. A date-only claim can return depends. Event-search completeness is tested, not proven.
It also serves dated Sun-sign horoscopes from the site's daily edition. It keeps the editions for the day before, the day of and the day after, so a reader in any time zone gets the reading written for their own date. Horoscopes are interpretation, for reflection.
Its sky calendar, horoscope panel and Chart Studio declare sidebar and conversation-panel entrypoints. Chart Studio asks for birth details inside its panel and calculates there; the assistant receives only a selection the person reviews and shares. The server offers no birth-chart storage, scheduling, eclipse search or predictions of personal outcomes.
Ask “What changes this week in Bangkok?”, “Is Mercury retrograde right now?” or “Show today's horoscope for Leo.” An answer should be useful in the conversation. Links to the Moon tool </moon-phase/>, lunar calendar </full-moon-calendar/> and methodology </methodology/> offer optional further exploration.
## Build and verify an integration
Zodiacs Developer provides skills for building with the engine, checking output and testing an integration. Its local stdio server adds natal-chart calculation and record comparison to the public-sky tools. It opens no listener or outbound connection. The existing local MCP adapter </developers/mcp/> remains available separately.
In a checkout, run npm ci and npm test in plugins/zodiacs-developer. The plugin contains pinned dependencies, three skills and runnable synthetic sky/calendar examples. Installation details and review evidence are in the plugin directory <https://github.com/zodiacs-org/site/tree/main/plugins/zodiacs-developer>.
## What local means
The developer server computes on its machine. The assistant provider can still receive the arguments and results. Hosted sky calculations run on Zodiacs infrastructure. Public-sky tools need no birth details; derived natal positions remain personal data. Read the AI integration privacy explanation </privacy/#ai-integrations> before connecting personal records.
Use the published calculation engine </developers/engine/> in external projects and preserve its notices. Site-derived candidate code retains the site's license. A receipt supports reproduction; it does not certify an imported record's authenticity or validate astrological interpretation.
For current support and known calculation limitations, see developer support </developers/support/> and independent-reference conformance </developers/conformance/>.
