# Consumer experience continuity — 2026-10-01

Owner request: implement the nine experience recommendations and publish them,
without a redesign. Existing layout, chart arithmetic, consent, and feature
availability remain the foundation.

| Recommendation | Implementation |
| --- | --- |
| Distinguish Today, Horoscopes, and Saved charts | Localized mobile menu descriptions and desktop navigation hints; Today and horoscope pages explain and link to each other. Non-English Today captions accurately describe their sign-based readings, while English describes the personal chart comparison. |
| Chart → understand → save → Today | First-reading introduction names the immediate payoff, the guide ends with Save as the primary action (year-ahead stays an explicit secondary choice), the save action explains its use with Today, and the saved result provides a personal daily-reading action. Someone else's saved chart returns to Saved charts instead of implying a personal reading. |
| Reassuring chart form | Birthplace instructions and unknown-time limitations simplified in all six UI catalogs; advanced house options reassure visitors that the default is usable. |
| Concrete horoscope language | Shared life-area descriptions simplified; daily reading removes “second vote” wording and gives more concrete home/group actions. Generated publications and deterministic copy receipts refreshed. |
| Precise accuracy | Homepage describes browser calculation instead of a broad accuracy promise; every English horoscope surface distinguishes computed positions from astrological interpretation. Source positions, event receipts, and methods retained. |
| Saving and privacy | Chart confirmation and profile introduction explain device storage and optional account sync. The optional Registry comparison has a plain description and birth-detail privacy guidance. |
| Useful return habit | Today, the home return card, reflection capture, and timeline explain reading → observation → later reflection, using existing persistence and explicit self-chart selection. |
| Explicit subscription action | Shared daily email copy says “Email my daily horoscope,” with a horoscope label and a clear sign-validation message. Existing placement after readings, consent, and unsubscribe behavior retained. |
| Explain unfamiliar destinations | Astrofolio navigation describes the official Zodiac token collection. The boundary scanner allows only the exact six owner-approved navigation descriptions; acquisition and market copy remain prohibited on astrology surfaces. |
