    Function vargaSensitivity

    • vargaSensitivity(
          natal: Chart | BirthInput,
          ayanamsa: AyanamsaName | AyanamsaDefinition,
          options?: VargaSensitivityOptions,
      ): VargaSensitivity

      The first millisecond before and after the birth at which each point's varga sign changes, in the engine's own arithmetic on the chart's clock (its input scale and any pinned ΔT), within horizonMinutes on each side. The birth is read as siderealChart reads it; a supplied Chart gives the instant, the place and the clock, and every position is computed again from them. Each change is the first millisecond at which the point's sidereal longitude, as siderealChart (for the mean nodes, chartPoints with the chart's ayanamsaValue) gives it, lies outside the varga run holding it at the birth: a run is the arc between two boundaries at which the sign changes, so a run can span a sign start.

      Malformed input throws RangeError: options that are not a plain object of data properties, an option key not named, points or vargas not given as an array, an unknown or repeated point or varga, cyclic other than true or false, a horizon that is not a whole number of minutes from 1 to 2,880, and whatever siderealChart refuses. What cannot be computed is a refusal on the rows it touches: no-angles and polar (beyond 66°) for the Ascendant, out-of-range for every row when the birth's UT1 or TT lies outside REFERENCE_SPAN, rate-bound for a point that moved as its bound says it cannot, and evaluation-budget for the point in progress and those after it once the call has made 2,000,000 evaluations. See docs/vedic.md.

      Parameters

      • natal: Chart | BirthInput
      • ayanamsa: AyanamsaName | AyanamsaDefinition
      • Optionaloptions: VargaSensitivityOptions

      Returns VargaSensitivity
