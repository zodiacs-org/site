    armc: number

    Right ascension of the midheaven, degrees.

    Readonlyayanamsa

    ayanamsa: CalcAyanamsaValue | null

    In the sidereal zodiac, the ayanamsa, degrees, whose true value is subtracted; null in the tropical zodiac.

    Readonlybounds

    bounds: { angles: CalcBound; cusps: CalcBound }

    In the sidereal zodiac, each includes the ayanamsa's own bound.

    Readonlycusps

    cusps: readonly number[]

    Twelve cusps from the first house, degrees in the true ecliptic of date, in the zodiac asked for; in the sidereal zodiac, whole-sign cusps start at the sidereal ascendant's sign.
