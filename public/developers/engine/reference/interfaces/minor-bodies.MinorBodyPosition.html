    Interface MinorBodyPosition

    A minor body's apparent geocentric place on the true ecliptic and equinox of date.

    interface MinorBodyPosition {
        body: "Chiron" | "Ceres" | "Pallas" | "Juno" | "Vesta";
        degree: number;
        dist: number;
        ephemeris: {
            body: { name: "jpl-horizons"; sha256: string; solution: string };
            name: string;
            version: string;
        };
        flags: readonly EphemerisFallback[];
        lat: number;
        lon: number;
        retrograde: boolean;
        sign: ZodiacSign;
        speed: number;
    }

    body: "Chiron" | "Ceres" | "Pallas" | "Juno" | "Vesta"

    Readonlydegree

    degree: number

    Longitude inside sign, degrees in [0, 30).

    Readonlydist

    dist: number

    Distance along the light path, au.

    Readonlyephemeris

    ephemeris: {
        body: { name: "jpl-horizons"; sha256: string; solution: string };
        name: string;
        version: string;
    }

    The Earth's and the Sun's ephemeris, as a chart names it ("jpl-de440" with the pack's SHA-256, astronomy-engine with its version, or the name of the source withEphemeris ran the call with), and the body's: its table, fitted to JPL Horizons's vectors from the solution it names, with its bytes' SHA-256.

    Readonlyflags

    flags: readonly EphemerisFallback[]

    "de440-unavailable" or "outside-de440-span" where astronomy-engine stood in for the shipped pack, as on a chart; otherwise none.

    Readonlylat

    lat: number

    Latitude, degrees.

    Readonlylon

    lon: number

    Longitude, degrees in [0, 360).

    Readonlyretrograde

    retrograde: boolean

    Readonlysign

    sign: ZodiacSign

    Readonlyspeed

    speed: number

    Longitude speed in degrees a TT day: the derivative of lon by a central difference over plus/minus MINOR_BODY_SPEED_STEP_DAYS of TT, both samples taking the central instant's decision about whether the body is behind the Sun's disc (from 3.0.0, as a planet's do); negative means retrograde.
