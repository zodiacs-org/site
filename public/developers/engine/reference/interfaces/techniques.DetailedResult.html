    Interface DetailedResult<T, F>

    A bare value (a Date, a longitude, a list of signs) with the label it cannot carry itself: the ephemeris its positions came from and the flags that say why that is astronomy-engine where the shipped DE440 pack was the default. What each …Detailed function of the techniques and internal entries returns, beside the plain function, which returns value alone and is unchanged.
