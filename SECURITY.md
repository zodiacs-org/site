# Security

## Reporting a vulnerability

Please report security problems privately, not in a public issue: by email
to admin@zodiacs.org, or through the **Report a vulnerability** button on
this repository's Security tab where GitHub shows it.

Say what you found, where (a URL, a file and line, or an API route), and how
to reproduce it. If the problem involves someone's birth details, use
invented details in the report.

## Scope

This repository holds zodiacs.org: the static site, the serverless functions
under `api/`, and the build and deployment scripts. Problems in the chart
engine itself belong to [zodiacs-org/engine](https://github.com/zodiacs-org/engine).
