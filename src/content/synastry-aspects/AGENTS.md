# Synastry reference sources

The three MDX articles are authored sources. Keep context, chart roles,
five geometry sections, examples, dates, review status, sources and FAQs
in the collection schema. No reversed-pair articles or additional pairs.

`src/data/aspect-reference-examples.json` is generated by
`node scripts/build-aspect-reference-examples.mjs`. Never edit it directly.
Run the generator with `--check` to verify deterministic drift. CI checks it.
The generator consumes the same aspect adapter and two-chart calculation
as the calculator. All timestamps are synthetic and nonpersonal.

Public release requires the recorded named editorial approval and indexing
evidence in `src/data/synastry-publication.json`. Until then the four routes
are absent from normal builds. `PUBLIC_SYNASTRY_REFERENCE_PREVIEW=1` builds
the local review edition with noindex and excludes it from the sitemap.
Preview availability is not editorial approval or release evidence.
